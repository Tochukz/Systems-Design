## Highly Scalable Image Sharing Platform - Additional Resources
__Search Optimized Databases & Technologies:__  
* [Elastic Search](https://www.elastic.co/guide/en/enterprise-search/current/start.html#start-search) - Enables developers to build search-powered applications using the [Elastic](https://www.elastic.co/) search platform. Elasticsearch is a proprietary search engine based on the [Lucene](https://en.wikipedia.org/wiki/Lucene) library, which provides a distributed full-text search engine with a very easy-to-use, web-based API over HTTP and JSON documents.

Here is an [example of a search query](https://www.elastic.co/guide/en/elasticsearch/reference/current/query-dsl-query-string-query.html) you can perform with Elastic Search to demonstrate its capabilities.

* [Apache Solr](https://aws.amazon.com/opensearch-service/) - A highly reliable, scalable, fault-tolerant, open-source enterprise search platform built on [Apache Lucene](https://en.wikipedia.org/wiki/Lucene).

* [MongoDB Atlas Search](https://www.mongodb.com/atlas/search) - Provides a unified API for the [MongoDB](https://www.mongodb.com/) database and the search.

Provides features like a Rich query DSL, Fuzzy search, Synonyms, Custom scoring, Autocomplete, and more.

* [OpenSearch](https://opensearch.org/) - A scalable, flexible, and extensible open-source software suite for search, analytics, and observability applications

__Image Compression__  
* [AWS, Serverless Image Handler](https://aws.amazon.com/solutions/implementations/serverless-image-handler/) - This solution creates a serverless architecture to initiate cost-effective image processing in the AWS Cloud. The architecture combines AWS services with [sharp](https://sharp.pixelplumbing.com/) open-source image processing software and is optimized for dynamic image manipulation.

* [GCP, Cloud CDN Dynamic Compression](https://cloud.google.com/cdn/docs/dynamic-compression) - Automatically compress responses served by Cloud CDN between the origin and the client. The size of the data sent over the network is reduced by 60% to 85% in typical cases.

* [Improve performance by compressing files in Azure CDN](https://learn.microsoft.com/en-us/azure/cdn/cdn-improve-performance)
